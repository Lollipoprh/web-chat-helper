fill_input 注入用例

用扩展对每个字段执行 fill_input，然后对照「期望」检查状态行。本地页面需先授权 http://localhost。

A. 原生必填输入

期望：写入成功，validityValid=true

B. 自定义 accessor（模拟组件库）

期望：model 被同步，validityValid=true

C. 拒绝 beforeinput

期望：失败，说明被 beforeinput 拦截

D. 回滚写入

期望：失败，说明被页面回滚

E. 富文本（contenteditable）

期望：写入成功，且退格 / 粘贴可用

F. 掩码（每 4 位加空格）

期望：成功并标注已格式化

G. 只在失焦时校验

期望：失焦后校验状态已更新

H. 自动保存（change 计数）

change 次数：0

I. 清空

期望：成功，字段为空
